# センサー記録プレビュー

**スマホだけで記録して、ZIP 1個を保存・共有できるプリリリースです。**

## インストールと記録

1. 下のAssetsから **Cadence-0.1.0-alpha.1-recorder.apk** をダウンロードして開く。
2. Cadenceで記録名を入力し、「記録を開始」。初回は通知を許可する。
3. 乗客として3〜5分記録し、「停止して保存」。まずは既定の50Hzでよい。
4. 保存済みの記録から「名前をつけて保存」。Androidの画面でフォルダとZIPの名前を選ぶ。
5. 「マイファイル」等からZIPを送るか、アプリの「ZIPを共有」を使う。

PC・ADB・USBデバッグは不要。ZIPは展開せず、そのまま送れます。
市街地走行と停車中の手振りを別々に記録し、固定／手持ち等のメモを添えてください。
[詳しい収集手順](https://github.com/lingmulongtai/Cadence/blob/v0.1.0-alpha.1/docs/recording.md)

## この版の範囲

- Android 8.0以降。専用の継続更新用署名を使う記録用debug APK。
- 記録名・日時・件数を一覧に保持。CSVとJSON端末情報を元のまま1つのZIPへ格納。
- 任意で100Hz、GPS速度・進行方向を選択。緯度・経度は記録しない。
- アプリ自身はネットワーク通信・自動送信なし。保存・共有先は利用者が選択。
- **モーションキュー、車両判定、手ぶれ除去は未実装。** 実機データの収集用。
- Samsung実機での品質・省電力による中断は未検証。記録中は画面を点灯したままにする。

アプリ内の記録はアンインストール／データ削除で消えるため、先にZIPを保存してください。
ローカル開発版と署名が違う場合、上書きインストールできません。

## 検証

18件のJVMテスト、debug/releaseのlint・ビルド、APK署名・権限境界を検証。
Android 16エミュレーターで、記録、再起動後の一覧、フォルダ・名前を選んで保存、
保存画面中のプロセス再生成、共有画面、ZIPと元データの完全一致を確認。
これらは実走行の受け入れを代替しません。

[画面と詳細な検証記録](https://github.com/lingmulongtai/Cadence/blob/v0.1.0-alpha.1/docs/verification/recorder-alpha.1.md)。
`SHA256SUMS` はAPKの照合用、`APK-SIGNATURE.txt` と `BUILD.txt` は署名・ビルド情報です。

English: Install the recorder APK, start/stop a recording, then use **Save as** to choose a ZIP filename and folder,
or **Share ZIP** to send it. No computer is required. This is a sensor collection preview; motion cues are not yet available.
